# 💸 Spill Bill Here

**Spill Bill Here** adalah website manajemen keuangan pribadi yang dirancang untuk membantu pengguna mencatat pemasukan dan pengeluaran, memantau saldo, serta mengelola keuangan dengan lebih teratur.

Project ini dikembangkan sebagai bagian dari tugas mata kuliah **Pemrograman Web Dasar (PWD)** menggunakan HTML, CSS, dan jQuery.

## ✨ Fitur Utama

- **Pencatatan Keuangan** — Membantu pengguna mencatat transaksi pemasukan dan pengeluaran.
- **Ringkasan Keuangan** — Menampilkan informasi keuangan untuk memudahkan pemantauan kondisi finansial.
- **Manajemen Transaksi** — Mendukung pengelolaan data transaksi sesuai fitur yang tersedia pada website.
- **Responsive Design** — Dirancang agar tampilan dapat menyesuaikan ukuran layar desktop maupun perangkat mobile.
- **Antarmuka Sederhana** — Menggunakan desain yang mudah dipahami dan nyaman digunakan.

## 🛠️ Teknologi yang Digunakan

| Teknologi | Kegunaan |
|---|---|
| HTML5 | Membuat struktur halaman website |
| CSS3 | Mengatur tampilan dan tata letak |
| JavaScript | Menambahkan interaktivitas |
| jQuery | Mempermudah manipulasi DOM dan penanganan event |

## 📁 Struktur Project

```text
Spill Bill Here/
├── index.html
├── style.css
├── script.js
├── UseCase.md
└── README.md
```

- `index.html` — Struktur utama halaman website.
- `style.css` — Mengatur desain, warna, tata letak, dan responsivitas.
- `script.js` — Menangani interaksi dan fungsi website.
- `UseCase.md` — Dokumentasi kebutuhan dan use case sistem.
- `README.md` — Dokumentasi utama project.

## 🚀 Cara Menjalankan Project

1. Clone repository:

   ```bash
   git clone git@github.com:Sakiih/PWD_TEORI_KELOMPOK_2.git
   ```

2. Masuk ke folder project:

   ```bash
   cd PWD_TEORI_KELOMPOK_2
   ```

3. Buka folder `Spill Bill Here` di Visual Studio Code.

4. Jalankan website dengan membuka file `index.html` menggunakan browser atau ekstensi Live Server di VS Code.

**Catatan:** Pastikan koneksi internet tersedia jika website menggunakan library jQuery atau font eksternal melalui CDN.
